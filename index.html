📘 สรุปสูตรความยาวรอบรูปและพื้นที่รูปสี่เหลี่ยม (ป.5)

🐱 สี่เหลี่ยมจัตุรัส

• ความยาวรอบรูป = 4 × ความยาวด้าน

• พื้นที่ = ความยาวด้าน × ความยาวด้าน

🐻 สี่เหลี่ยมผืนผ้า

• ความยาวรอบรูป = 2 × (กว้าง + ยาว)

• พื้นที่ = กว้าง × ยาว

🐰 ด้านขนาน & ขนมเปียกปูน

• ความยาวรอบรูป = บวกความยาวทั้ง 4 ด้าน

• พื้นที่ = ความสูง × ความยาวฐาน

🚀 วิธีนำเกม AR นี้ขึ้น GitHub และฝัง (Embed) ในเว็บไซต์หรือ LMS

ขั้นตอนที่ 1: สร้าง Repository และอัปโหลดไฟล์ลง GitHub

1. เข้าสู่ระบบ GitHub.com แล้วกด New repository ตั้งชื่อ เช่น ar-quad-math-p5 (เลือกเป็น Public)
2. บันทึกไฟล์เกมนี้เป็นชื่อ index.html แล้วกด Add file > Upload files ลากไฟล์ index.html ขึ้นไป แล้วกด Commit changes

ขั้นตอนที่ 2: เปิดใช้งาน GitHub Pages (จำเป็นสำหรับกล้อง AR บนเว็บ!)

ไปที่แท็บ Settings > Pages ในหัวข้อ Build and deployment > Branch ให้เลือก main และโฟลเดอร์ / (root) แล้วกด Save รอประมาณ 1–2 นาที จะได้ลิงก์แบบ HTTPS เช่น:
https://ชื่อผู้ใช้ของคุณ.github.io/ar-quad-math-p5/ 💡 หมายเหตุ: GitHub Pages ใช้ HTTPS โดยอัตโนมัติ ทำให้เบราว์เซอร์อนุญาตให้เปิดกล้อง AR ได้อย่างปลอดภัย

ขั้นตอนที่ 3: คัดลอกโค้ด <iframe> ไปฝัง (Embed) ใน Google Sites / เว็บโรงเรียน / Moodle
<iframe src="https://YOUR-USERNAME.github.io/ar-quad-math-p5/" width="100%" height="760" style="border:0; border-radius:20px;" allow="camera; microphone; fullscreen" loading="lazy"></iframe>
